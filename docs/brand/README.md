# SpotMe brand

The Cradle mark: one cupped hand under the volt spot ("spot me", "I've got you"). Masters are the SVGs; text in
the wordmarks is SF Pro Rounded Heavy converted to outlines, so they render the same anywhere.

| File | Use |
|---|---|
| `icon.svg` / `icon.png` | App icon, full-bleed 1024 square (the OS masks it) |
| `icon-tinted.svg` / `.png` | iOS tinted home-screen icon |
| `mark.svg` | The mark alone on transparent, for dark backgrounds |
| `wordmark*.svg` / `.png` | Mark + "SpotMe", on black or transparent |

Colours: volt `#CCFF3D` on black. The glow suits dark backgrounds only. SF Pro's licence covers apps on Apple
platforms; check it before using the wordmark elsewhere.
