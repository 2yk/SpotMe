Reviewer and planner: Fable. Builders: Opus agents. Date: 6 Oct 2026. Asked by Yeshu: "review current screens,

Canvas: SpotMe Designs, https://claude.ai/artifact/5zqv25yapNuDwotbEqNvwQ. Files: `design/canvas/project/`.

## What is wrong today (from the code in `Apps/Watch/Views`, build 6)

1. **You can't read which exercise you're on.** The name sits in the top bar between Back and the clock, where
   about 11 letters fit: "Machine Chest Press (or Flat Bench)" shows as "Machine Ch…". After the first set an
   Undo button joins the same bar.
2. **The numbers that matter are small.** After a set the next weight is a 13 pt line under a big ring; the
   reason is 11 pt. On the break the next exercise and its weight are 13 pt and 11 pt.
3. **Six colours compete.** Every kind of exercise has its own tint (volt, ice, violet, ember, grey), on badges,
   buttons, rings and the screen background, so colour stops meaning anything.
4. **Today's rows spend a fifth of the width on a round icon** and hide the target weight in grey text.
5. **Nothing says what to beat.** The plan is "same weight, more reps", but last time's reps aren't on the set screen.
6. **Small inconsistencies:** Finish is pink like a warning, Done is mint on one screen and Start is volt on
   another, dialogs need a scroll to reach the buttons, a rest day still offers Start workout.

## The direction

- **One accent.** Volt is the thing to tap and the value the Crown moves. Other colours only carry a state:
  ice = waiting (rest, break), mint = done, ember = lighter than planned, red = heart rate and destructive,
  amber = paused. No colour per exercise kind, no violet, no tinted screen backgrounds.
- **Name on the screen, count in the bar.** The top bar holds only short things ("Set 2 of 4", "Rest", "Next").
  The exercise name is in the content at 17 pt bold, two lines if needed.
- **Numbers are the heroes.** Weight and reps at 36 pt on the set screen, the countdown at 54 pt, the next
  weight at 28 pt with an arrow when it changed.
- **The timer runs round the edge of the screen**, so the middle is free for the time and what to load next.
- **Same place every time.** The one primary action is a full-width volt capsule at the bottom.

Behaviour changes Yeshu has to agree to (everything else is layout only):

| # | Change | Why |
|---|---|---|
| a | Set screen shows "Last 9": the reps of the same set last session | It is what "aim for more reps" needs |
| b | Undo moves from the set screen's top bar to the rest and break screens (bottom centre) | That is where a wrong entry is noticed, and it empties the top bar |
| c | Today rows drop the round kind icons; target weight goes right, with an up or down arrow from the engine's tag | More room for names; the day's changes show at a glance |
| d | A rest day (Saturday) shows no Start workout button | Nothing to start |
| e | End workout is one screen with three buttons instead of a scrolling system dialog | No scroll to reach Keep going |
| f | "Back to list" under All done goes away | The Back button is already there |

Every board is one `.dc.html` file in `design/canvas/project/`, written directly with the Write tool
(never generated by a script). Do not edit `canvas.json`: the planner owns it. Do not publish.

- A watch board is 416 × 496 px = the 46 mm screen at 2×. **1 pt = 2 px.** All sizes below are px.
- All styling inline (`style="…"`). Lay out with flex and `gap`. Close every element, quote every attribute.
- No `{{holes}}`, no emoji, no em-dashes, no HTML comments left in the file. Real `<button>` for anything tappable, with `aria-label` when it has no text.
- Text is literal. Use the exact strings in the board list. En dash in ranges ("6–10"), "×" in prescriptions, "·" as separator.
- Fonts differ between this server (Nunito) and Yeshu's devices (SF Rounded): leave every text line at least 8% spare width, never rely on an exact fit.

## How the planner checks a board

`cd design/canvas/build && python3 render.py check <files>` must print "ok" for the board (no text outside,
cut or overlapping, nothing under 20 px, tap targets 60 px or more; it measures the drawn letters, so tight line-heights are fine), then the planner looks at the rendered
picture (`render.py sheet out.png <files>`). Builders run `check` themselves before reporting, and look at their
own sheet with the Read tool.
